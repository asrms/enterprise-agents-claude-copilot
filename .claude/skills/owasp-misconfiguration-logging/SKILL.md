# Skill: Security Misconfiguration and Logging/Monitoring (OWASP A05:2021, A09:2021)

## Implementation Rules:
- **[ARCHITECTURE]** Secure per-environment configuration with fail-closed defaults: separate profiles (`application-prod.yml`, per-environment Pydantic `Settings`, `NODE_ENV=production`), startup blocked if a security variable is missing (secrets, CORS origins, base URL), repeatable hardening via IaC verified in CI with `trivy config .` or Checkov.
- **[MANDATORY]** Security headers on every response: a restrictive `Content-Security-Policy` (`default-src 'self'; object-src 'none'; base-uri 'none'; frame-ancestors 'none'` plus nonces for scripts, without `'unsafe-inline'`/`'unsafe-eval'`), `Strict-Transport-Security: max-age=31536000; includeSubDomains`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, a minimal `Permissions-Policy`, `Cross-Origin-Opener-Policy: same-origin`; `Cache-Control: no-store` on APIs with personal data; implemented with Spring Security `headers(h -> h.contentSecurityPolicy(...))`, `helmet()` in Node, dedicated middleware in FastAPI.
- **[FORBIDDEN]** Stack traces, exception messages, SQL queries, and framework versions in responses: Spring `server.error.include-stacktrace=always`, `include-message=always`, `include-exception=true`; Express with a handler that sends `err.stack` or `NODE_ENV` not set to `production`; FastAPI `HTTPException(detail=str(exc))` or `traceback.format_exc()` in the body; return a generic error (RFC 9457 `ProblemDetail`) with a correlation id and keep the details in the logs.
- **[FORBIDDEN]** Debug in production: Flask `app.run(debug=True)`/`FLASK_DEBUG=1` (Werkzeug console = code execution), `FastAPI(debug=True)`, `uvicorn --reload`, Django `DEBUG = True`, Spring Boot DevTools in the production artifact (declare it `optional`/`developmentOnly`) and above all a populated `spring.devtools.remote.secret`, Node `--inspect=0.0.0.0`.
- **[MANDATORY]** Default credentials and secrets: disable or change default accounts (admin/admin, RabbitMQ `guest`, Tomcat manager, Grafana, Jenkins), no static `spring.security.user.password`; the log line "Using generated security password" indicates that only the default configuration is active; passwords and keys only from a secret manager, never in versioned `application.yml`, `.env`, or `docker-compose.yml`.
- **[MANDATORY]** Actuator and administrative endpoints: in production `management.endpoints.web.exposure.include=health,info` (plus `prometheus` on an internal port), `management.endpoint.health.show-details=never` or `when-authorized`, `management.endpoint.env.show-values=never`, a separate management port (`management.server.port`) not exposed by the ingress; never expose `heapdump`, `env`, `configprops`, `threaddump`, `loggers`, `jolokia`, `gateway`, `shutdown` without authentication.
- **[CONFIGURATION]** API documentation and consoles: `springdoc.api-docs.enabled=false` and `springdoc.swagger-ui.enabled=false` in production if the API is not public, FastAPI `FastAPI(docs_url=None, redoc_url=None, openapi_url=None)`, admin panels and `/metrics` reachable only from an authenticated management network.
- **[FORBIDDEN]** Directory listing and serving sensitive files: Nginx `autoindex on`, Apache `Options Indexes`, Express `serve-index`, `express.static` on the project root (exposes `.env`, `.git/`), `*.bak`, `*.sql`, `*.zip` backups in the web root.
- **[FORBIDDEN]** CORS `*` on non-public APIs: `app.use(cors())` without options (= `Access-Control-Allow-Origin: *`), `CORSMiddleware(allow_origins=["*"], allow_credentials=True)` in Starlette/FastAPI (with cookie-bearing requests it reflects the caller's `Origin`), `allowedOriginPatterns("*")` with credentials in Spring (CWE-942).
- **[CONFIGURATION]** Runtime hardening: non-root containers (`USER 10001`), read-only filesystem, images with pinned tags or digests (never `latest`), banner removal (`app.disable('x-powered-by')` or helmet, uvicorn `--no-server-header`), `INFO` log level and the `org.hibernate.orm.jdbc.bind` logger no higher than `WARN` in production.
- **[MANDATORY]** Security events to record (ASVS V7, OWASP Logging Cheat Sheet): successful and failed logins, logout, lockout, password reset and change, MFA enable/disable, role and privilege changes, denied access (401/403), invalid tokens or signatures, CSRF violations, administrative operations, exports of sensitive data, security configuration changes; minimum fields: UTC ISO-8601 timestamp, `event`, outcome, actor id, source IP, user agent, resource, `correlation_id`.
- **[FORBIDDEN]** Sensitive data in logs (CWE-532): passwords and hashes, session IDs, JWTs, refresh and reset tokens, API keys, `Authorization` and `Cookie` headers, PANs (at most the first 6 and last 4 digits), CVVs, health data, full request/response bodies; no `log.info("{}", request)` on DTOs with sensitive fields — use `@ToString.Exclude`, Pydantic `SecretStr`, pino `redact`, Logback masking.
- **[MANDATORY]** Log injection neutralization (CWE-117): structured JSON logs (Logback `logstash-logback-encoder` or Spring Boot `logging.structured.format.console=ecs`, Python `structlog` with `JSONRenderer`, Node `pino`) with user values as fields and never concatenated into the message; with text layouts neutralize `\r`, `\n`, and control characters (Log4j2 `%enc{%m}{CRLF}`, Logback `%replace(%msg){'[\r\n]', '_'}`).
- **[MANDATORY]** Correlation id generated at ingress (or accepted from the `traceparent`/`X-Correlation-Id` header only if it matches a strict pattern), propagated with MDC in Java, `contextvars` in Python, `AsyncLocalStorage` in Node, included in every log line, and returned in the generic error.
- **[MANDATORY]** Immutable audit trail: security events forwarded in real time off the host to the SIEM (Splunk, Elastic, Microsoft Sentinel), append-only/WORM storage (e.g. S3 Object Lock in compliance mode), verifiable integrity (hash chain or batch signing), defined retention (PCI DSS v4.0 req. 10.5.1: 12 months, 3 of them immediately available), read-only access separate from application administrators.
- **[MANDATORY]** Alerting with concrete thresholds and runbooks: more than 10 failed logins per minute per account or more than 100 per IP, spikes of sequential 403/404s from a single user (IDOR scanning), MFA deactivation or role change on privileged accounts, admin access outside business hours, repeated JWT signature errors; every rule has an owner and a response time.
- **[REVIEW]** Grep for misconfigurations: `debug\s*=\s*True`, `FastAPI\(.*debug=True`, `app\.run\(.*debug`, `include-stacktrace|include-message|include-exception`, `exposure\.include.*\*|include: "\*"`, `show-details:\s*always`, `spring-boot-devtools`, `allow_origins=\[\s*"\*"`, `cors\(\)`, `autoindex on`, `serve-index`, `printStackTrace\(\)`, `err\.stack`, `format_exc\(\)`.
- **[REVIEW]** Grep for logging (case-insensitive): `(log|logger|logging|console)\.(info|debug|warn|warning|error|log)\(.*(password|passwd|pwd|secret|token|authorization|cookie|cardnumber|pan|iban|cvv)`, `console\.log\(req\.(body|headers)`, `logging\.\w+\(f".*request`, concatenations `+ request.getParameter(` in log messages.
- **[SECURITY]** A logging failure must not block the application but must raise an alert; log files with `0640` permissions and a dedicated owner; no `DEBUG` or `TRACE` level logs in production, because they can include bodies, SQL parameters, and headers.
- **[PERFORMANCE]** Asynchronous logging (Logback `AsyncAppender`, Log4j2 async loggers, pino with a worker-thread transport) with a bounded queue; for the audit appender `neverBlock=false` and no loss allowed, sampling permitted only for access and debug logs, never for security events.
- **[TESTING]** Automated tests: a 500 response contains no stack trace or class names; security headers are present (integration test or `curl -sI` in CI, ZAP baseline scan); a failed login produces the `auth.login.failure` event with a correlation id and without the password; input with `\r\n` does not generate extra log lines.
- **[CWE]** A05:2021: CWE-16, CWE-756, CWE-942, CWE-1004, CWE-614, CWE-611; verbose errors CWE-209 (officially mapped to A04:2021) and directory listing CWE-548 (mapped to A01:2021) are reported under A05 for consistency with the category description; active debug CWE-489; A09:2021: CWE-778, CWE-117, CWE-532, CWE-223.
